# The board

- **`smashandclash.tldraw`**: the board from the film. Open it in tldraw Desktop, choose **Run Script**, and play.
- **`script/`**: the same board script as loose files. To put the game on any board, open that board, choose **Develop → Reveal Script…**, and copy both files into the folder it opens.

`script/main.js` is the client and `script/smashandclash-sdk.js` is the vendored SDK (`npm run vendor-sdk` refreshes it). How it works: [../docs/how-it-works.md](../docs/how-it-works.md).
